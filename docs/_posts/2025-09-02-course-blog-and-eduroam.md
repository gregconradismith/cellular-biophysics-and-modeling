The domain cellularbiophysicsandmodeling.com was being blocked because W&M Information Technology categorized it as a "new domain." IT has added it to the allow list, so it should work on campus/eduroam now.

If you are still having trouble accessing the course blog at https://cellularbiophysicsandmodeling.com/ try switching browsers (such as Safari, Chrome, or Firefox). You might also clear your browser’s cache and cookies, then reload the page. If that does not work, try using an incognito window and/or rebooting your computer. If none of this works, please contact Information Technology itsupport@wm.edu and cc me when you do (gdsmit@wm.edu).
