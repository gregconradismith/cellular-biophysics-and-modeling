A **student** asked: Is it okay to type problem set answers instead of handwriting them?

The **professor** responded: For sketches and derivations, it is important that the work be done by hand. Practice writing legibly, because you will need to do so on exams. Do not turn in typeset mathematics or use a word processor unless an assignment explicitly asks for that format.

The kinesthetic aspect of learning mathematics matters. Writing out graphs, derivations, and equations by hand is part of how the material becomes usable.
